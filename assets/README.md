# MMORPG Asset Repository

This directory contains raw design assets, concepts, AI prompts, audio drafts, and documentation for the project.

## Directory Structure

- `assets/raw/textures/`: Raw texture files, prompt outputs, and reference images.
- `assets/raw/audio/`: Raw audio files, sound effects, and music drafts.
- `assets/raw/design/`: Game Design Documents (GDD), balance spreadsheets, and lore drafts.
